\subsubsection{负环 (Negative Cycle Detection - SPFA)}
SPFA 检测全图负环：全部点以距离 0 入队，用松弛路径边数判环。
\begin{lstlisting}
bool negative_cycle(const vector<vector<pair<int,ll>>>& g){
    int n=int(g.size())-1; // vertices 1..n
    vector<__int128_t> dist(n+1,0);
    vector<int> length(n+1,0);
    vector<char> in(n+1,true);queue<int> q;
    for(int i=1;i<=n;i++)q.push(i);
    while(!q.empty()){
        int u=q.front();q.pop();in[u]=false;
        for(auto [v,w]:g[u])if(dist[v]>dist[u]+w){
            dist[v]=dist[u]+w;length[v]=length[u]+1;
            if(length[v]>=n)return true;
            if(!in[v])q.push(v),in[v]=true;
        }
    }
    return false;
}
\end{lstlisting}

\paragraph{多测与注意} 局部变量可直接多测，图由调用方重建。这里检测全图负环；若只查源可达负环则仅将源入队。SPFA 最坏 $O(nm)$。
