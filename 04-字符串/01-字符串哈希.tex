\subsection{字符串哈希 (String Hashing)}
用于 O(n) 预处理，O(1) 查询任意子串的哈希值。
这个板子好像挺容易冲突的，建议双 hash。
\begin{lstlisting}
const ll mod=180181327,bs=31;
ll pw[1000010];
ll h[1000010],n;
char c[1000010];
ll get(ll l,ll r){
    return (h[r]-pw[r-l+1]*h[l-1]%mod+mod)%mod;
}
int main(){
    pw[0]=1;f(i,1,1000000)pw[i]=pw[i-1]*bs%mod;
    scanf("%1000000s",c+1);n=strlen(c+1);h[0]=0;
    f(i,1,n)h[i]=(h[i-1]*bs+(c[i]-'a'+1))%mod;
}
\end{lstlisting}


\paragraph{使用条件与多测} 幂表固定底数／模数时仅预处理一次；每组重建 h[0..n]。本实现只适用于小写字母，查询非空且边界合法。哈希相等并非严格相等，建议独立双模数随机底数，或在要求确定正确时使用后缀数组／直接校验。
