\subsection{C++ 手动上下取整}
众所周知 c++ 的负数取整逻辑是向 0 取整，强需要向下/上取整的时候很麻烦。

\begin{lstlisting}
ll Ceil(ll x,ll y);
ll Floor(ll x,ll y){
    if(y<0)x=-x,y=-y;
    if(x>=0)return x/y;
    else return -Ceil(-x,y);
}ll Ceil(ll x,ll y){
    if(y<0)x=-x,y=-y;
    if(x>=0)return (x+y-1)/y;
    else return -Floor(-x,y);
}
\end{lstlisting}
