\subsection{C++ 手动上下取整}
C++ 商向零截断，按余数符号修正为向下／向上取整。
\begin{lstlisting}
ll Floor(ll x,ll y){
    ll q=x/y,r=x%y;
    return q-(r!=0&&((r<0)!=(y<0)));
}
ll Ceil(ll x,ll y){
    ll q=x/y,r=x%y;
    return q+(r!=0&&((r<0)==(y<0)));
}
\end{lstlisting}

\paragraph{多测与注意} 无共享状态。默认除数非零且商能由 ll 表示；按余数符号修正，避免 x+y-1 的额外溢出。
