\subsubsection{圆方树 (Round-Square Tree)}
依赖前文 Biconnected：先 run()，再调用下列函数。圆点编号 $1..n$，第 $k$ 个点双对应方点 $n+k+1$。孤立点保留为单个圆点，不额外生成一元方点；非连通图得到圆方森林。多测返回全新的邻接表，时间空间 $O(n+m)$。
\begin{lstlisting}
vector<vector<int>> block_cut_forest(const Biconnected& b){
    vector<vector<int>> tree(b.n+b.blocks.size()+1);
    for(int k=0;k<int(b.blocks.size());k++){
        if(b.blocks[k].size()==1)continue;
        int square=b.n+k+1;
        for(int u:b.blocks[k]){tree[u].push_back(square);tree[square].push_back(u);}
    }
    return tree; // skipped singleton squares are unused IDs
}
\end{lstlisting}

\paragraph{多测与注意} 依赖前文 Biconnected，先 run 再调用；返回新的邻接表，多测不需额外清理。非连通图得到森林，孤立圆点保留。
