\subsection{笛卡尔树 (Cartesian Tree)}
笛卡尔树 (Cartesian Tree)，一种基于键值和权值的二叉树，使用栈 O(n) 线性构建。
\begin{lstlisting}
ll a[10000010];
int l[10000010],r[10000010];
long long x,y;
int st[10000010],tp;
int main(){
	n=d;tp=0;
    f(i,1,n)l[i]=r[i]=0;
    if(n==0)return 0;
    f(i,1,n)a[i]=d;
	st[++tp]=1;
	f(i,2,n){
		while(tp&&a[i]<a[st[tp]])l[i]=st[tp--];
		if(tp)r[st[tp]]=i;st[++tp]=i;
	}
}
\end{lstlisting}


\paragraph{使用条件与多测} 每组必须清空当前 $[1,n]$ 的左右儿子与栈顶（代码已补）；根为构建后的 st[1]，同值按下标先后稳定处理。已将栈和左右儿子改为 int，内存从约 320 MB 降至约 200 MB；容量仍应按题目缩减；值的类型按题目决定。
