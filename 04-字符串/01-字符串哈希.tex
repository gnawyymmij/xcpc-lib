\subsection{字符串哈希 (String Hashing)}
用于 O(n) 预处理，O(1) 查询任意子串的哈希值。
这个板子好像挺容易冲突的，建议双 hash。
\begin{lstlisting}
const ll mod=180181327,bs=31;
ll pw[1000010];
ll h[1000010],n;
char c[1000010];
ll get(ll l,ll r){
    return (h[r]-pw[r-l+1]*h[l-1]%mod+mod)%mod;
}
int main(){
    scanf("%s",c+1);n=strlen(c+1);h[0]=0;
    pw[0]=1;f(i,1,n)pw[i]=pw[i-1]*bs%mod;
    f(i,1,n)h[i]=(h[i-1]*bs+(c[i]-'a'+1))%mod;
}
\end{lstlisting}

\paragraph{多测与注意} 每组重建 h，幂表也可按最大长度预处理一次。小写字母版本；实战建议双模数 hash。
